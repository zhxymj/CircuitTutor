## 面向通信设备低压 MCU 与 I2C 传感接口子板的 AI 候选约束与原理图工程验证系统

本项目聚焦通信设备 5V/3.3V 低压 MCU 与 I2C 传感接口子板，在研发前期提供中文需求解析、CircuitJSON 候选生成、硬件规则检查、确定性修复、SPICE/准仿真、KiCad 导出与外部复验。其他接口和驱动元件属于目录覆盖，不作为本轮同等成熟的主场景。

方案采用“AI 提出，规则验证；验证通过才晋级，验证失败则拒绝或回退”。当前稳定交付以 A 主线“AI 辅助原理图设计合规性检查与自动修复”为核心；B 方向已实现隔离式路由任务合同、奖励函数、评价器和规则回退，PCBWorld/PPO 因本次环境可行性门未通过而保持实验性，不影响 A 主线运行。

> 产品名为“智绘电路”，本包中项目目录名为 `智绘电路`。

## 场景与能力边界

支持范围：

- 当前验收场景为低压 5V/3.3V MCU 与 I2C 传感接口子板；
- 其他电源、通信接口和驱动元件仅有目录或模板覆盖，成熟度须逐例核验；
- CircuitJSON、SVG、KiCad、SPICE、BOM 和 PCB 预布局输出；
- 离线模板演示，以及配置外部模型后的自然语言生成。

不在当前范围：

- 高压、强电、射频功放、安全关键系统和任意复杂工业电路；
- 未经器件手册、SPICE 与 KiCad 复验即可投产的自动设计；
- 已完成训练并验证提升的 PPO 自动布线模型；
- 未显式声明 I2C 地址、供电上下限或电源轨电压时，系统不会猜测；当前电压规则只检查器件 PWR_IN 供电兼容性，不覆盖完整接口逻辑电平、时序和电平转换设计。

所有输出都是研发辅助结果，最终正确性由确定性工程规则、器件手册、仿真及 KiCad ERC/DRC 复验共同确认。

## 技术架构

```text
中文需求
  -> 结构化需求规格
  -> CircuitJSON / 元件与连接候选
  -> 结构合法性检查
  -> 33 个确定性 ERC 检查器
  -> 额定值 / 功耗 / 工程惯例检查
  -> SPICE 或准仿真
  -> 错误解释与修复候选
  -> 修复后再次运行确定性检查
  -> KiCad 官方 ERC 复验
  -> 原理图 / BOM / SPICE / PCB / 证据报告
```

责任边界：

- AI：理解需求、发现缺失项、提出元件与拓扑候选、解释错误、排序修复候选；
- 硬件规则：引脚类型、电源/地冲突、输出竞争、极性、LED 限流、续流、去耦、悬空、耐压、功耗等确定性判定；
- SPICE/KiCad：工作点或指定分析、官方 ERC/DRC、独立于 AI 的外部复验。

B 方向通过 `routing_job.json` 隔离：

```text
智绘电路 -> .kicad_pcb + routing_job.json
          -> 外部 PCBWorld 服务（可选）
          -> 候选 .kicad_pcb
          -> 独立 KiCad DRC
          -> 达标晋级；失败保留原板并回退
```

核心进程不导入 PCBWorld、PyTorch 或 Gym。`POST /api/routing_job` 只校验和转交合同，不假装已经完成 PPO 布线。

5. 删除限流电阻或 LED，展示 `/api/erc` 实时重算和定位；
6. 恢复安全电路，导出 KiCad/BOM/SPICE/PCB；
7. 打开 `evidence/compliance_results.json` 与 `evidence/generation_results.json`，说明数字可追溯；
8. 展示 `experiments/pcbworld/feasibility_result.json`，明确 B 方向当前降级与回退。

### 每个样本必须留下的记录

记录样本 ID、原始来源与许可证、数据划分、输入文件 SHA-256、运行配置/命令、原始输出、转换结果、失败原因、适用门禁及状态、统计分子/分母和复现方式。缺少某项验证时写 `incomplete`；不适用时写 `not_applicable` 并说明原因。模型自检、内部模板、构造缺陷集和单个成功案例都不能替代 KiCad/ERC/DRC、仿真或工程师复核，也不能作为任意电路准确率。

## 局限性与安全提示

- 目前高分指标来自固定、规模有限的构造集和内置模板，需要用独立公开数据与保留集继续验证泛化；
- 工程估算不能替代器件手册、完整 SPICE、信号完整性/电源完整性分析和人工评审；
- 已有内部 CAD 有源候选板与官方 PCB 校验证据；B 方向 PPO 未完成环境门，未实物上电；
- API Key 由启动脚本从环境变量或本地 `.env` 读取，不打印、不写入日志和证据；当前私人演示包按用户要求保留 `.env`，通用发布脚本默认排除该文件；
- 默认仅监听本机回环地址。
