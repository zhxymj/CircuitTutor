## 已交付的数据

- 每板固定 Git commit，保存未修改的原理图、原始硬件许可证、署名、来源 URL、文件大小与 SHA256。SparkFun 硬件为 CC-BY-SA-4.0；OLIMEX 硬件为 Apache-2.0。软件与硬件许可分开核实，未复用上游执行代码。
- 30 个 Eagle 案例完整抽取原始元件、命名网络、gate/pin 到 package/pad 映射。30/30 引脚引用与封装焊盘引用审计通过，SDA/SCL 直接连接的子电路单独留存。
- 新增 90 条外部来源关联的中文任务，每板 3 条：原图接口重建、供电/主控电平/上拉条件缺项、SDA/SCL 短接冲突。原有 80 条内部任务保留。
- 外部开发分区 22 板/66 条，预留评测分区 8 板/24 条，整设计族分区，跨分区家族泄漏 0。开发者在导入时阅读过源文件与任务，因此这不是独立盲测。

供电域只记录原图网络名称，不把 `VCC`、`VIN` 等名称推断成确定电压。元件 `value/deviceset` 是原图身份线索，尚未逐件完成制造商、正式 MPN、数据手册与 KiCad 封装核对。1.8V 芯片内核、供电转换、GNSS、RF、Ethernet 等原始板功能可能超出 3.3V/5V MCU/I2C 接口范围，保留原图不表示接纳全部功能。

## CircuitJSON v2 提取的边界

30 个 Eagle 原图生成 `circuit_v2_unconverted.json` 拓扑草稿：结构与 v2 元数据检查通过。原始 gate/pin 名编码后保留，原图实际单焊盘映射与多焊盘映射分别记录；原始完整网络仍留在 `source_nets`。

图框、标志、基准点及没有参与可表示连接的部件不塞入编辑图节点，原始清单保留在 `extracted_topology.json`，草稿另记 `excluded_unconnected_or_graphical_parts` 和单端网络。没有猜测缺失的真实 MPN、制造商、数据手册或 KiCad 封装。

全部源器件在**未转换草稿**中保持 `external_eagle_unmapped`，30/30 草稿被封闭器件目录门禁明确拒绝。目录转换与源电气接受均为 1/30（`sparkfun_qwiic_adapter`，2026-10-14）；按全部 32 块源板计为 1/32，另 2 块 OLIMEX legacy KiCad 仍为 `not_converted`。此草稿供目录映射和人工审阅，不能当作前端支持全部 Eagle 器件或可直接生产的电路。

首例的接受范围与残余项见[改造执行状态](改造执行状态.md)的 2026-10-14 小节：接受只表示候选与固定源提交在网表、物理焊盘与焊盘铜几何上一致，不覆盖丝印/禁止区/装配层/3D 模型、主机侧上拉与连接器数据手册额定值，不构成制造放行。其余 29 个 Eagle 草稿状态不变，不能从 1/30 外推。

KiCad 10.0.6 CLI 对原始 Eagle 适配板执行网表导出返回“加载原理图失败”，没有生成网表。不能把 Eagle XML 解析记成 KiCad 官方读回。两板 legacy KiCad 在本外部数据工作中尚未抽取网络或运行 ERC。

## 数据目录与复现

正式数据位于 `data/external_references/`：

- `manifest.json`：固定版本、许可、署名、原始文件 SHA256。
- 各源板目录的原始 `.sch`、许可证、`SOURCE_ATTRIBUTION.md`、`extracted_topology.json` 与未转换 v2 草稿。
- `offline_audit.json`：逐板结构、真实引脚与焊盘、网络事实和实际缺项。
- `external_requirement_tasks.json`：30 个源关联案例、90 条任务和分区。
- `source_linked_task_audit.json`：分母和整族分区验证。
- `conversion_results.json`：逐例转换状态与具体目录拒绝原因。
- `external_preplanning_initial.json`、`external_preplanning_results.json`：初次/当前真实本地预规划。
- `acquisition_failures.json`：未采纳候选、网络失败及官方工具读回失败。
- `sparkfun_candidates.json`：公开仓库发现清单，采集脚本需要的默认分支信息；不计数据案例。

在项目目录执行：

```powershell
python -X utf8 -B -m evaluation.external_reference_audit --output data/external_references/offline_audit.json
# 首例转换与源电气接受需要官方 KiCad CLI；缺 CLI 时 parity 记为 incomplete，不会静默降级
$env:KICAD_CLI_PATH='C:\Users\30789\Desktop\智绘电路工具链\kicad\bin\kicad-cli.exe'
python -X utf8 -B -m evaluation.external_reference_cases --convert-source sparkfun_qwiic_adapter
python -X utf8 -B tests/test_external_reference_cases.py
python -X utf8 -B tests/test_eagle_footprint_repro.py
```

仅需要重新获取公开源文件时执行：

```powershell
python -X utf8 -B data/external_references/collect_sparkfun.py --fetch --archives
```

归档采集先要求逐仓库硬件许可证审核记录，再核对固定 commit 的许可证文本；原始源文件不改。下载缓存和探测文件保留在 `fetch_cache/` 供问题追溯，发布包排除该目录，避免将整仓库附带的非目标代码、模型或附件混入正式样例。
