## 工程台操作位置

正式页面为 A 方案“专业工程台”。左侧在需求、元件和文件之间切换；中央画布显示当前原理图；右侧“元件属性”跟随画布选择，可直接修改真实元件参数。“电路校验”读取当前电路并运行适用的工程门禁，缺工具或信息时显示未完成。底部“检查与过程”展开生成、规则检查与估算明细，顶部“运行校验”可进入工程校验。右上角“导出”分为“原理图与物料”（SVG/BOM/KiCad）、“SPICE与仿真”和“PCB与制造候选”。

窄屏使用画布上方的“需求 / 元件”和“属性 / 校验”展开相应侧栏，再关闭侧栏返回画布。搜索元件后插入当前电路；“文件”区按“工程文件、图片识别、代码与外部电路、工程与过程、视图与设置”分组，包含当前 JSON、历史工程及候选入口。图片和代码仍先生成候选，经过原有审核流程后再应用。

本轮该工作台支持拖拽调整模块尺寸：左、右栏之间的竖分隔条与“检查与过程”上沿的横分隔条均可拖动，聚焦分隔条后方向键微调、双击或 `Home` 恢复响应式默认，尺寸按浏览器记忆（`localStorage` 键 `zht-layout`）；窄屏自动隐藏分隔条。

本轮另加入可选「教学模式」（教育方式），开关在“文件 → 视图与设置”分组内，默认关闭并按浏览器记忆（`localStorage` 键 `zht-teach`）。开启后关键术语显示虚线下划线、悬停或键盘聚焦弹出中文解释；左侧出现「描述需求→生成电路→审核与编辑→运行校验→导出文件」学习路径并高亮当前步骤；校验结果每项门禁附一句“为什么查这项”；空状态出现三步引导卡；选中元件时属性面板底部出现教学卡（这是什么 / 为什么需要 / 常见错误，并引用门禁报告中与该器件相关的真实问题原文）。教学层只挂在 `html[data-teach="on"]` 下，默认关闭时与既有行为一致，只读当前工程状态，不改变电路、校验与导出结果，也不请求任何外部资源；器件说明覆盖 31 类常见器件，未覆盖类型给通用解释而不编造。

## 建议演示顺序

1. 输入“5V LED 限流指示灯，串联330欧电阻”，生成离线电路，确认来源徽章显示“模板回退”。查看元件、连线、ERC 与仿真摘要；模板回退不计为 AI 生成成功。
2. 选中电阻修改参数，观察“已手动修改”、ERC 重算和撤销；保存 JSON 并再次载入，或“保存到历史”后从历史载入。导出 SVG、BOM、SPICE、KiCad 工程。KiCad ZIP 解压后打开工程或运行其中的 `OPEN_IN_KICAD.bat`。面向教学或评审讲解时，可在“文件 → 视图与设置”打开“教学模式”，演示术语解释、学习路径当前步骤、门禁“为什么查这项”与元件教学卡；该开关只改变呈现，不改变上述任何电气与导出结果，讲解完毕可立即关闭。
3. 保留当前编辑，输入“3.3V MCU 连接 I2C 传感器”，查看具体型号等补充问题；缺项期间原画布、参数和撤销栈保持。跳过问题仍会被服务端要求补充。目录外器件、明确矛盾或无匹配模板会说明拒绝原因，不以其他模板替换原工程。
4. 打开“代码建电路”，载入 RC 示例并生成。查看真实 tscircuit 原理图、Circuit JSON、转换与统一校验结果，再在审核面板决定接受。接受后可修改电阻参数、保存、撤销参数修改，再撤销候选应用；语法错误、不支持的 IC 和取消生成均保留原画布。
5. 导入图片并选择“本机 CircuitVision”，查看原图、检测框、mask 和 HCD 线段/点。逐一补漏、校正类型与数值，明确确认各器件引脚网络后形成候选。原始识别、人工校正、候选审核及电气验证是不同阶段；几何交叉点与线段不会自动成为已确认电气网络。
6. 查看已有有源 MCU/传感器制造候选 `data/pcb_active/run_e34bf9d7ac6c45be85d4fb00b97e1fec/manifest.json`，演示其官方 ERC、网表、DRC 与源电路一致性证据。现有证据中 `manufacturing_release=false`，此步骤展示已保存的工程候选与校验，不表示已实物上电或获制造放行。需重新走制造路径时，先载入对应工程，用“真实PCB”生成候选，在 KiCad 完成布线，再提交“校验制造文件”。

## 结果与限制

| 路径 | 当前可验证结果 | 需要区分的内容 |
|---|---|---|
| 中文离线需求 | 受支持的需求匹配模板；缺项澄清，冲突与不支持需求拒绝 | 模板回退、LLM 草稿和官方验收是不同状态 |
| 代码建电路 | 本机生成 Circuit JSON/SVG，统一校验、审核、应用、编辑和撤销 | 不支持元件或语法错误不应用；预览完成不等于通过电气验收 |
| 图片识别 | 本机检测、mask、几何候选及人工校正 | 原始预测与校正后候选分别保留；完整拓扑仍需人工确认 |
| 工程输出 | JSON/SVG/BOM/SPICE/KiCad 与已有制造候选证据 | KiCad 门禁结果和待工程师、板厂复核状态分别展示 |
