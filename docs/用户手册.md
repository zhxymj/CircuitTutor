# 用户手册 · 智绘电路 CircuitTutor

面向最终用户（学生 / 教师 / 电子爱好者）的操作指南。

## 改造功能使用补充（2026-09-26）

- 本机用根目录 `START_DEMO.bat` 启动，自动加载 F 盘工具链。手动运行先执行 `. .\tools\activate_toolchain.ps1`。
- AI 改图和图片导入先显示候选审核：核对新增/修改/删除器件和连接、错误位置、原图与识别文字。通过官方门禁后按钮显示“接受修改”，否则显示“应用未验证草稿”。
- 接受、编辑、撤回或载入 JSON 后自动重新校验，旧结果不作为当前图的通过证明。
- 图片 OCR 字符可能识别错误。审核原文、置信度及原图后，人工填写实际数值和引脚；“下载原始识别证据”保存本次结果。
- “预布局”输出布局草稿。“真实PCB”要求 v2 图具备真实器件、封装、引脚/焊盘映射和板框信息，输出未布线板。
- 完成 KiCad 布线后点击“校验制造文件”，提交实际 `.kicad_pcb`。源原理图门禁、焊盘审计、官方网表一致性和 DRC 全部通过后，下载待电子工程师及板厂复核的包；失败时先按报告修正。

各项功能的当前覆盖范围和未完成验收见 `docs/改造执行状态.md`。

## 1. 这是什么

智绘电路是一个 **AI 辅助原理图设计合规性检查平台**：

1. 输入一句**中文**电路需求
2. 自动生成**原理图**
3. 自动运行 **33 个电气规则检查器（ERC）**
4. 可做 **SPICE 仿真 / 准仿真**
5. 一键导出 **KiCad 工程 / SPICE 网表 / BOM / PCB / SVG**

不需要安装任何 Python 依赖；有浏览器就能用。

## 2. 启动

### 方式 A：本机直接跑

1. 确认已安装 **Python 3.10+**
2. 在项目目录执行：

```bash
python -B server.py
```

3. 浏览器打开 <http://127.0.0.1:8765/>

> Windows 也可双击 `启动演示.bat`。

### 方式 B：Docker

```bash
cp .env.template .env    # 可选：填入 API Key
docker-compose up --build
```

浏览器打开 <http://127.0.0.1:8765/>

界面补充：生成成功后可看到元件/连线数量；ERC 明细带修改建议；AI 改图后可「撤回更改」；导出 KiCad 时请用「打开工程」而非「导入」。

### 有无 API Key 的区别

| | 有 Key | 无 Key |
|---|---|---|
| 能否打开页面 | 能 | 能 |
| 能否生成电路 | 能（AI 生成） | 能（自动匹配 40 套内置模板） |
| ERC / 导出 / 手动编辑 | 全部可用 | 全部可用 |
| AI 增量修改当前电路 | 可用 | 不可用（需配置模型） |

未配置 Key 时**不会报错**，会自动回落到内置教学模板，演示不中断。

配置 Key（PowerShell）：

```powershell
$env:DEEPSEEK_API_KEY = 'sk-xxxxxxxx'
python -B server.py
```

## 3. 如何输入中文需求

### 3.1 基本写法

在顶部输入框写一句自然语言，点「生成电路」。例如：

- `用555定时器做一个LED闪烁灯`
- `5V电源给红色LED限流，用330欧电阻`
- `做一个NPN三极管开关驱动蜂鸣器`
- `两个LED并联，共用一个限流电阻`
- `电位器分压输出 0~5V 可调电压`

页面下方还有示例芯片，点一下即可填入。

### 3.2 写得更准的技巧

| 写法 | 效果 |
|---|---|
| 写明电源电压：`5V` / `12V` | 限流电阻按该电压计算 |
| 写明元件：`555` / `LED` / `三极管` / `运放` | 优先匹配对应拓扑 |
| 写明参数：`330Ω` / `10k` / `100uF` | 直接采用你给的值 |
| 写清连接意图：`共射放大` / `反相` | 减少歧义 |

**建议**：一句话里至少包含「电源 + 主要元件 + 功能」。  
过短的输入（如只写「灯」）可能会触发**需求澄清**。

### 3.3 需求澄清

若输入有歧义，页面会先弹出澄清面板，列出几种理解方式供你选择；  
你也可以自己补充说明。确认后系统再生成。

清晰需求不会打扰，直接生成。

### 3.4 选择 AI 模型

点输入框右侧的 **「模型」** 按钮：

1. 选提供商（DeepSeek / 通义 / GLM / Kimi / OpenAI / 自定义）
2. 选具体模型
3. 非服务端默认提供商时填入你自己的 API Key
4. 点「保存并选用」

> Key 只保存在你的浏览器与本次会话内存中，2 小时后自动销毁，不会写入磁盘或日志。

### 3.5 用中文修改当前电路

生成或载入电路后，在“修改当前电路”输入框写修改指令，例如：

- `把 R1 改成 470Ω`
- `增加一个 100nF 去耦电容并接在电源和地之间`
- `把 LED 改为蓝色，并重新计算限流电阻`

系统只在候选电路通过结构、元件/引脚白名单和 ERC 质量门禁后应用结果。模型失败、候选结构非法或新增致命/严重问题时，原电路和画布保持不变；请求期间若你又手动改了电路，过期的 AI 结果也不会覆盖新修改。

## 4. 生成过程中你会看到什么

顶部进度条会依次显示：

1. **模型** — 当前使用的 AI 模型
2. **元件** — 识别到的元件（本地命中时 0 次 AI 调用）
3. **规划 / 生成** — AI 设计电路
4. **结构修复 / ERC 修复** — 发现问题自动纠正（若有）
5. **工程惯例补全** — 自动补去耦电容、按键上拉等
6. **参数精确化** — 例如 LED 限流电阻按欧姆定律 + E12 系列取值
7. **额定值 / 准仿真** — 电流、电压、功耗提示
8. **完成** — 画布渲染出原理图

生成失败时会自动切换内置模板，并在界面上标明「你看到的是哪个内置电路」。

## 5. 如何理解 ERC 检查结果

### 5.1 结果在哪里看

- **状态栏徽章**（画布右下）：
  - `ERC 全部通过 ✔` — 无致命/严重问题
  - `致命 n · 严重 n · 提示 n · 警告 n` — 有分项计数
- 点击徽章或相关入口可打开 **「ERC 检查明细」面板**
- 画布上问题引脚会被红圈/标注标出

### 5.2 严重程度

| 级别 | 含义 | 你该做什么 |
|---|---|---|
| **致命（fatal）** | 电路结构错误，基本无法工作 | 必须修：短路、悬空引用、0Ω 短路等 |
| **严重（major）** | 很大概率不能正常工作 | 应修：未共地、LED 缺限流、芯片未供电、极性反接等 |
| **提示（minor）** | 不规范或可能有隐患 | 建议修：未连接元件、重复连接、单点网络等 |
| **警告（warning）** | 工程惯例问题 | 建议改进：缺去耦电容、缺续流二极管、悬空输入等 |

`passed = true` 表示**没有致命和严重**问题（提示/警告仍可能存在）。

### 5.3 常见检查器类别（当前共 33 个）

| 规则名 | 级别 | 说明 |
|---|---|---|
| 重复位号 | fatal | 元件 id 必须唯一 |
| 幻觉引脚 | fatal | 引脚名不在元件库定义内 |
| 悬空引用 | fatal | 连接引用了不存在的元件 |
| 电源短路 | fatal | VCC 与 GND 直接短路 |
| 0Ω电阻短路 | fatal | 电阻值为 0 |
| 网络竞争 / 电源冲突 / 输出冲突 | fatal/major | 多个输出硬连在一起 |
| 未知元件 | major | type 不在 151 种元件库中 |
| 连接不完整 | major | 一条连接不足两个引脚 |
| LED缺限流电阻 | major | LED 串联支路无限流 |
| 极性反接 | major | 电解电容/LED/二极管极性接反 |
| 未共地 | major | 电路没有 GND |
| 芯片未供电 | major | IC 缺 VCC/GND |
| 多电池极性冲突 | major | 多个电源极性矛盾 |
| 电容极性提示 / LED限流电阻过小 | warning | 参数偏危险 |
| 悬空输入 / 缺续流二极管 / 缺去耦电容 | warning | 工程惯例 |
| 并联供电输出 | warning | 多电源并联输出 |
| 未连接元件 / 重复连接 / 自环连接 | minor | 结构冗余或未接线 |
| 单点网络 / 输出脚悬空 | minor | 网络只有一个端点 |
| 接插件引脚悬空 | minor | 接插件有脚未接 |
| 电解电容无防反接提示 | minor | 教学提示 |

### 5.4 编辑后 ERC 会自动重算

在画布上**拖动、改值、删除、插入、连线**之后，系统会在约 0.3 秒后自动重新检查，  
徽章和明细面板会跟着刷新——不需要重新点「生成」。

## 6. 画布操作

| 操作 | 方式 |
|---|---|
| 选中元件 | 点击 |
| 拖动 | 按住拖到新位置 |
| 改参数 | 选中后在右侧属性面板改 value 等字段 |
| 旋转 | 工具条旋转按钮，或按 `R` 键 |
| 插入元件 | 工具条下拉选类型 → 自动插入画布中央 |
| 连线 | 进入连线模式后依次点两个引脚；「取消连线」退出 |
| 删除 | 选中后删除（支持撤销） |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` 或工具条按钮 |
| 缩放 | 工具条放大 / 缩小 / 重置 |
| 主题 | 顶部或工具条切换原理图配色（印刷/蓝图/KiCad 风格等） |

插入的元件需要**手动连线**；未连线的元件会被 ERC 标为「未连接元件」。

## 7. 如何导出

生成或编辑完成后，工具条按钮会亮起。

### 7.1 导出 KiCad 工程
1. 点 **「导出KiCad」**
2. 得到 `智绘电路-KiCad-<时间戳>.zip`
3. **完整解压**到本地文件夹（不要在压缩包预览里双击）
4. 打开 KiCad 8/9 → 项目管理器 → **「打开工程」**
5. 选择解压目录中的 **`*.kicad_pro`**（ASCII 文件名，如 `5V_330_LED.kicad_pro`）
6. 在项目管理器中双击同名 **`*.kicad_sch`** 进入原理图；元件应可见
7. 可继续 ERC、改图、出网表、画 PCB

**不要用「文件 → 导入」**，也不要只打开 `.kicad_sym` / `.zip`——那不是打开本工程，界面会像“啥都没有”。解压包内 `HOW_TO_OPEN.txt` 与 `preview/*.svg` 可先确认原理图内容。

压缩包内含：
压缩包内含：

- `.kicad_sch` 原理图
- `.kicad_pro` 工程
- `CircuitTutor.kicad_sym` 符号库
- `sym-lib-table` 库表

> 未安装 KiCad 也可导出；只是本机「官方 ERC 联动校验」会自动跳过。

### 7.2 导出 SPICE 网表

1. 点 **「SPICE」**
2. 得到 `.cir` 文件（ngspice 兼容）
3. 可用 ngspice / LTspice 等工具打开仿真

### 7.3 导出 BOM

1. 点 **「BOM」**
2. 得到 CSV（Excel 可直接打开，含中文表头）
3. 列：序号 / 类型 / 参数值 / 封装 / KiCad封装 / 额定 / 数量 / 位号
4. 同值同类型自动合并数量；电源标记（VCC/GND）不计入采购清单

### 7.4 做 SPICE 仿真

1. 工具条选择分析类型：`op`（直流）/ `ac`（交流）/ `tran`（瞬态）/ `dc`（扫描）
2. 点 **「仿真」**
3. 查看节点电压、幅频/瞬态结果、解析解对照

说明：

- 本机装了 **ngspice** 时优先真仿真
- 未安装时自动用**解析解**（LED 电流 / RC 幅频 / 分压等教学近似）
- 这是教学级分析，不能替代专业 SPICE 精度

### 7.5 导出 PCB 预布局

1. 点 **「PCB」**
2. 得到 `.kicad_pcb`
3. KiCad 打开可看到板框 + 元件网格占位 + 位号丝印

> 这是**原型草稿**，不是可直接打板的成品布线。

### 7.6 导出 SVG / 保存工程

| 按钮 | 作用 |
|---|---|
| 导出 SVG | 原理图图片，可插入文档/PPT |
| 保存 JSON | 本地保存工程文件，下次「载入」继续编辑 |
| 存档 | 保存到服务端工程历史（见下节） |

## 8. 工程历史

- 点 **「存档」**：把当前电路保存到本地历史库
- 点 **「历史」**：浏览、载入、删除已保存的工程
- 每条记录含：标题、原始需求、元件数、连接数、完整电路

工程历史默认存在项目目录下的 `data/history`，整包复制到别的机器或盘符后历史随之可用；可通过 `LSQC_HISTORY_DIR` 指定其他位置。发布打包（`tools/build_release.py`）会把该目录排除在发布包之外。

## 10. 常见问题 FAQ

### Q1：不填 API Key 还能用吗？

能。会自动匹配内置 40 套拓扑模板，ERC、手动编辑、导出全部可用。  
只是不能理解任意自由描述的新电路，也不能使用自然语言增量修改当前电路。

### Q2：点了「生成电路」很久没反应？

1. 检查网络与 API Key 是否有效
2. 看进度条是否停在某一阶段
3. 若超过约 1–2 分钟，点浏览器刷新后重试
4. 系统有调用预算上限，超限会自动回落模板，不会无限等待

### Q3：生成结果和我想要的不一样怎么办？

- 改写需求，写明电源、主要元件、拓扑（如「共射」「反相」）
- 用「多方案」看是否有更接近的候选
- 在“修改当前电路”中用一句话调整参数、元件或连接；门禁失败会保留原图
- 直接在画布上改：拖动、改值、插入元件、连线，ERC 会跟着重算

### Q4：ERC 显示「未共地」怎么办？

在画布插入 `gnd` 元件，并把电源负极与各回流点连到同一 GND 网络。

### Q5：ERC 显示「LED缺限流电阻」怎么办？

在 LED 串联支路中插入电阻。  
5V + 红光 LED 时，经验值约 330Ω（约 9mA）。

### Q6：导出的 KiCad 打不开？

1. 确认解压后再打开 `.kicad_pro`（不要在压缩包内直接双击）
2. 使用 **KiCad 8 或 9**
3. 若提示缺少工程，选「仍要打开」打开 `.kicad_sch`
4. 符号库已内嵌在工程内，一般无需再配置库路径

### Q7：SPICE 仿真报错或结果为空？

- 先确认电路 ERC 无致命错误
- 无 ngspice 时只提供解析解，复杂电路结果可能有限
- IC 类元件在 SPICE 中是黑盒子电路桩，不会做晶体管级仿真

### Q8：BOM 里为什么没有 VCC / GND？

它们是电源标记符号，不是实物元件，不进入采购清单。

### Q9：如何让局域网同学访问？

启动前设置：

```powershell
$env:LSQC_HOST = '0.0.0.0'
$env:LSQC_PORT = '8765'
python -B server.py
```

其他电脑访问 `http://你的IP:8765`。

注意：

- 会暴露服务，请只在可信局域网使用
- LLM 端点默认每 IP 每分钟 30 次，防止刷爆 Key 余额

### Q10：Docker 启动失败？

1. 确认 `.env` 存在（可从 `.env.template` 复制）
2. 端口 8765 是否被占用
3. 查看日志：`docker-compose logs -f circuittutor`

### Q11：测试怎么跑？

```bash
python -B tests/run_tests.py
```

41 个套件，离线可跑，不需要 API Key；在线固定需求评测只有显式执行 `python -B -m evaluation.ai_requirements_benchmark --online` 时才调用已配置模型。
只跑部分：

```bash
python -B tests/run_tests.py kicad
```

### Q12：数据会不会上传？

- 生成请求会发到你配置的 LLM 提供商（如 DeepSeek）
- 工程历史存在项目目录下的 `data/history`（可用 `LSQC_HISTORY_DIR` 覆盖）
- API Key 不进 URL、不打日志；当前私人演示包按用户要求将其保留在项目根目录 `.env`，请勿对外分发
- `/api/trace` 链路日志仅存内存，不含 Key 与完整 prompt
